# Revert Metals (working name)

A startup plan for turning US titanium scrap into defense-grade titanium slab in a new US melt shop. Scrap is secured by contract, the slab is proven with trial melts at an existing furnace, and a 2028 site study picks the plant's location. Prepared October 14, 2026.
